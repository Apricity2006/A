# X 运营指标与复盘 Playbook

## 1) 核心指标（按目标分层）

### 增长目标
- Impressions（曝光）
- Profile Visits / Impressions（主页访问率）
- Follows / Profile Visits（关注转化率）

### 互动目标
- Engagement Rate = Engagements / Impressions
- Replies per Post（平均回复数）
- Reposts + Likes 结构比（判断内容传播性 vs 认同度）

### 转化目标
- Link Click Through Rate（链接点击率）
- Leads / Clicks（线索转化率）
- Sales / Leads（销售转化率，若可追踪）

## 2) 诊断顺序

1. 先看曝光趋势（是否有触达问题）
2. 再看互动结构（钩子与内容是否匹配受众）
3. 最后看转化链路（CTA 与落地页是否一致）

## 3) A/B 测试最小闭环

- 每次只改 1 个变量：
  - Hook
  - 贴文长度
  - 发布时间
  - 是否带图片/视频
  - CTA 类型
- 单轮观察窗口：7 天
- 保留同主题对照样本，避免结论失真
